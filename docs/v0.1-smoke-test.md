# Claude Pets v0.1 Smoke Test

Run before publishing `@open-pets/claude-pets@0.1.0`.

## Package

- [ ] `bun test` passes.
- [ ] `bun run typecheck` passes.
- [ ] `bun run build` emits `dist`.
- [ ] `bun pm pack --dry-run` contains only intended files.
- [ ] Packed tarball install works in a temp project.

## OpenPets prerequisites

- [ ] `@open-pets/core@0.1.0` is available to the install path.
- [ ] `@open-pets/client@0.1.0` is available to the install path.
- [ ] OpenPets desktop is installed/running.

## Claude project install

- [ ] `bunx @open-pets/claude-pets install` writes `.claude/settings.local.json`.
- [ ] Re-running install is a no-op.
- [ ] Old `claude-pets` hook commands are replaced by the current command.
- [ ] Unrelated hooks are preserved.
- [ ] `bunx @open-pets/claude-pets install --dry-run` writes nothing.
- [ ] `bunx @open-pets/claude-pets uninstall` removes only Claude Pets hooks.
- [ ] `bunx @open-pets/claude-pets uninstall --dry-run` writes nothing.

## Runtime

- [ ] Restart Claude Code after install.
- [ ] Prompt submit changes pet to thinking.
- [ ] Edit tool changes pet to editing.
- [ ] Bash/test command changes pet to testing/running.
- [ ] Stop/StopFailure changes pet to success/error.
- [ ] `bunx @open-pets/claude-pets test-event thinking` updates OpenPets.

## Privacy

- [ ] Hook execution does not log raw hook payloads.
- [ ] No prompts, diffs, command output, or file contents are sent to OpenPets.
